- **B2** เลขที่รีเซ็ตรายวัน + ลำดับร่วมทุกสาขา + ใบเสร็จย้อนวันที่ (C2) ใช้กับใบกำกับภาษีได้ไหม
- **B6** รายได้สกุลต่างประเทศ: ส่วนต่างอัตราแลกเปลี่ยนตอนรับเงิน — 1C เก็บยอดบาทที่เข้าบัญชีจริงและส่วนต่างไว้ให้แล้ว (ข้อ 4.4)

## 1. ขอบเขต

**ทำใน 1C**
- ใบเสร็จรับเงิน (RE): รับเงินจากลูกค้ารายเดียว สกุลเดียว ตัดได้หลายใบแจ้งหนี้ · รับบางส่วนได้ · วิธีรับ โอน / เช็ค / เงินสด / อื่นๆ
- หัก ณ ที่จ่ายที่ลูกค้าหักจริง + เลขที่/วันที่ 50 ทวิ + แนบไฟล์ (C4) · ค่าธรรมเนียมโอนที่ถูกหัก
- สกุลต่างประเทศ: ยอดบาทที่เข้าบัญชีจริง + ส่วนต่างอัตราแลกเปลี่ยน (เก็บไว้ส่งนักบัญชีใน 1D)
- ยกเลิกใบเสร็จพร้อมเหตุผล → ยอดค้างของใบแจ้งหนี้กลับมา
- ใบแจ้งหนี้: ยอดรับแล้ว/ค้างชำระจริง · ป้าย "ชำระครบ / ชำระบางส่วน" · แท็บ "ชำระครบ" · ปุ่ม "บันทึกรับเงิน"
- ใบวางบิล: ปุ่ม "บันทึกรับเงินตามใบวางบิลนี้" (เติมใบแจ้งหนี้ให้ครบ)
- หน้าพิมพ์ใบเสร็จ A4 ไทย/อังกฤษ
- รายงานลูกหนี้คงค้างแยกอายุ (C5) รายลูกค้า + เจาะดูรายใบ

**ไม่ทำใน 1C**
- ใบกำกับภาษี / ใบลดหนี้ / ใบเพิ่มหนี้ → ก่อนจด VAT (รอ B1, B3)
- รับเงินล่วงหน้า/มัดจำก่อนมีใบแจ้งหนี้ · รับเกิน (เงินเหลือเก็บไว้ตัดใบหน้า) → รอ B5 (ตอนนี้ต้องรับไม่เกินยอดค้าง)
- ตัดหนี้สูญ / ปัดเศษยอดค้างเล็กน้อยทิ้ง → ภายหลัง (ตอนนี้ยอดค้างเศษยังค้างอยู่ — ใช้ค่าธรรมเนียมแทนได้ถ้าเป็นค่าธรรมเนียมจริง)
- กระทบยอดธนาคาร / ลงบัญชี GL → เฟส 3 (ข้อมูลทุกช่องออกแบบให้ลงบัญชีย้อนหลังได้)
- แท็บการเงินในโปรเจกต์ / Excel ส่งนักบัญชี → **1D**

## 2. ภาพรวม flow

```
IV-…01 ค้าง 53,500 ┐
IV-…02 ค้าง 10,700 ┼─► [บันทึกรับเงิน] ลูกค้า A · THB · โอนเข้า กสิกร xxx · วันที่ 15 ต.ค.
                   ┘     ตัด IV-…01 53,500 + IV-…02 10,700 = 64,200
                         หัก ณ ที่จ่าย 1,800 · ค่าธรรมเนียม 0 → เงินเข้าจริง 62,400 (ตรงกับสเตทเมนต์)
                         ─► ยืนยัน ─► RE-20261015-000001 (ออกทันที — C1)
                         ─► IV-…01 ชำระครบ · IV-…02 ชำระครบ
                         ─► แนบ 50 ทวิ (ตอนนั้นหรือทีหลัง)

ใบวางบิล BN-… ─► [บันทึกรับเงินตามใบวางบิลนี้] ─► หน้าเดียวกัน เติมทุกใบในใบวางบิลให้
ยกเลิก RE (เหตุผล) ─► ยอดรับแล้วของทุกใบที่ตัดลดกลับ ─► ใบแจ้งหนี้ค้างชำระอีกครั้ง
```

สมการของใบเสร็จ (สกุลของใบ — ตรวจใน backend ทุกครั้ง):

**ยอดตัดหนี้รวม = เงินเข้าจริง + หัก ณ ที่จ่าย + ค่าธรรมเนียม**

## 4. กติกาธุรกิจ

### 4.1 บันทึกรับเงิน (= ออกใบเสร็จ)
- เลือกลูกค้า → (สกุลเงิน) → ใบแจ้งหนี้ที่ออกแล้วและยังค้าง · ติ๊กแล้วยอดตัดเริ่มต้น = ยอดค้างทั้งหมด แก้ให้น้อยกว่าได้ (รับบางส่วน)
- หัก ณ ที่จ่าย: ระบบเสนอ = ผลรวม (ยอดหักโดยประมาณบนใบแจ้งหนี้ × ยอดตัด ÷ ยอดรวมใบ) · แก้ได้ · 0 ≤ หัก ≤ ยอดตัดรวม
- เงินเข้าจริง = ยอดตัด − หัก − ค่าธรรมเนียม (ต้อง > 0 ยกเว้นทั้งหมดเป็นหัก ณ ที่จ่าย — ไม่อนุญาต ต้องมีเงินเข้า) · แสดงตัวใหญ่ให้เทียบกับสเตทเมนต์
- วันที่ (C2-ก): ไม่ใช่วันในอนาคต · ไม่เกิน 30 วันย้อนหลัง · ไม่ก่อนวันที่ออกของใบแจ้งหนี้ทุกใบที่ตัด
- โอน: ต้องเลือกบัญชีที่เงินเข้า (เปิดใช้งาน) · บัญชีสกุลต่างจากใบได้ (เช่น ใบ USD เงินเข้าบัญชีบาท — ธนาคารแลกให้)
- เช็ค: เลขที่เช็ค + ธนาคาร + วันที่หน้าเช็ค บังคับ (C6)
- ยืนยันในหน้าต่างสรุป → ล็อกใบแจ้งหนี้ทุกใบ (คำสั่งเดียว เรียงตาม id **ก่อน** SELECT ธรรมดา — บทเรียนจากใบวางบิล) → ตรวจซ้ำทุกข้อ → ได้เลข RE ตามวันที่ใบเสร็จ → เพิ่มยอดรับแล้วของแต่ละใบ

### 4.2 หลังออก
- แก้ตัวเลข/ใบที่ตัด/วิธีรับไม่ได้ (เอกสารการเงิน — แผนแม่บทหลักการข้อ 2)
- **แก้ได้เฉพาะข้อมูล 50 ทวิ** (เลขที่ วันที่ ไฟล์) และบันทึกภายใน — เพราะลูกค้าส่ง 50 ทวิ ตามมาทีหลัง · ทุกครั้งเข้า audit log
- ยกเลิก: ต้องมีเหตุผล · เลขยังอยู่ · ยอดรับแล้วของทุกใบที่ตัดลดลงตาม · ใบแจ้งหนี้กลับเป็นค้างชำระ (และยกเลิกใบแจ้งหนี้ได้ถ้าไม่มีใบเสร็จอื่น)

### 4.3 ใบแจ้งหนี้กับใบวางบิล
- ใบแจ้งหนี้ที่มีใบเสร็จไม่ยกเลิก → ยกเลิก/ออกใหม่แทนไม่ได้ (กติกานี้มีใน 1B แล้ว ข้อความบอกให้ยกเลิกใบเสร็จก่อน)
- ใบวางบิลที่ออกแล้วไม่เปลี่ยนเมื่อรับเงิน (ยอด ณ วันวางบิล) · ร่างใบวางบิลแจ้งปัญหาใบที่รับชำระครบแล้ว (มีใน 1B แล้ว)
- รับเงินจากหน้าใบวางบิล: เติมใบที่ยังค้างในใบวางบิลนั้นให้ (ใบที่รับครบไปแล้วข้าม)

### 4.4 สกุลต่างประเทศ
- ยอดตัดหนี้/หัก/ค่าธรรมเนียม เป็นสกุลของใบแจ้งหนี้ · กรอก "ยอดบาทที่เข้าบัญชีจริง" เพิ่ม (บังคับ)
- ระบบคำนวณอัตราจริง + ส่วนต่างอัตราแลกเปลี่ยนเป็นบาท (บวก = กำไร ลบ = ขาดทุน) แสดงบนหน้าดู ไม่พิมพ์บนใบเสร็จ — ใช้ส่งนักบัญชีใน 1D (การรับรู้จริงรอ B6)
- ไม่มี QR / พร้อมเพย์ ไม่เกี่ยว

### 4.5 ลูกหนี้คงค้าง (C5)
- ใบแจ้งหนี้ที่ออกแล้ว ยอดค้าง > 0 · แยกอายุจากวันครบกำหนดเทียบวันนี้เวลาไทย: ยังไม่ถึงกำหนด / 1–30 / 31–60 / 61–90 / > 90
- ตารางรายลูกค้า (ยอดเป็นบาท — สกุลต่างประเทศคิดยอดค้าง × อัตราของใบแจ้งหนี้) + รวมทุกช่อง · กดลูกค้าเห็นรายใบ (ยอดค้างสกุลเดิม) · กดใบไปหน้าใบแจ้งหนี้
- ดูย้อนหลัง "ณ วันที่" → ภายหลัง (ต้องคิดยอดรับ ณ วันนั้นจากใบเสร็จ — ข้อมูลพอแล้ว)

| R-C13 | ยอดค้างของใบแจ้งหนี้ใหญ่ หลายร้อยใบในรายงานลูกหนี้ | SQL รวมยอดใน DB (GROUP BY) · ดัชนี `idx_inv_status_due` มีแล้ว |
| R-C14 | หน้าพิมพ์ใบเสร็จถูกใช้แทนใบกำกับภาษีหลังจด VAT | ตอนจด VAT ต้องทำ B1 ก่อน — ใส่ใน checklist ก่อนจด VAT (เอกสารวงจรขาย) · ตอนนี้หน้าพิมพ์ไม่มีคำว่า "ใบกำกับภาษี" |
