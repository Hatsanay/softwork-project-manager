## รอบ 2 (13 ต.ค. 2026) — เจ้าของระบบขอ "แบบโมเดิร์นสวยๆ ทันสมัย"
หน้าตัวอย่างลิงก์เดิมปรับเป็นแบบนี้ (ยังใช้สีธีมเดิมทั้งหมด — ไล่เฉดเฉพาะในช่วงฟ้า blue-500→blue-600 ที่ระบบใช้อยู่):
- **แถบข้างเป็นการ์ดลอย** มุมโค้งใหญ่ พื้นขาวโปร่งแสง · ช่อง "ค้นหาโปรเจกต์ งาน (Ctrl K)" ใช้ API ค้นหาของแดชบอร์ดที่มีอยู่แล้ว · ตัวเลขนับข้างเมนู (เช่น โปรเจกต์ 12)
- **เมนูที่เลือก** ค่าเริ่มต้นเป็นแคปซูลฟ้าไล่เฉดมีเงาฟ้า (ทางเลือก: ฟ้าอ่อน)
- **แถบบนโปร่งแสงแบบกระจก** ลอยเหนือเนื้อหา · พื้นหลังหน้ามีแสงฟ้าจางด้านบน
- **แดชบอร์ด**: การ์ดต้อนรับพื้นฟ้าไล่เฉด + ลายตารางจาง + สรุปตัวเลขแบบกระจก · การ์ดตัวเลขมีกราฟเส้นเล็ก (sparkline) และป้ายเพิ่ม/ลด · วงแหวนสถานะงาน · รูปสมาชิกซ้อนกันในรายการโปรเจกต์ · จุดสีความเร่งด่วนของงาน
- **หน้ารายการ**: การ์ดสรุปจำนวนบนตาราง · ตัวกรองแบบแคปซูลมีตัวเลข · รูปผู้ใช้มุมโค้งพื้นไล่เฉดอ่อน · เมนู "อื่นๆ" แบบลอย
- **หน้าฟอร์ม**: เมนูหัวข้อด้านซ้ายติดจอ · การ์ดแต่ละหัวข้อมีไอคอน · ช่องกรอกมีไอคอนนำหน้า · ช่องลากไฟล์ · สวิตช์เปิด/ปิด · บอกผลตรวจถูกต้องเป็นสีเขียวใต้ช่อง · แถบ "ยังไม่บันทึก" สีเข้มลอยกลางล่าง
- **หน้าเข้าสู่ระบบ**: ฝั่งแบรนด์สีถ่านไล่ไปฟ้า + ลายตารางจาง + การ์ดกระจกแสดงตัวอย่างความคืบหน้า
- กราฟเล็กใช้ SVG ที่เขียนเอง ไม่เพิ่มไลบรารีกราฟ

## หลักการ
1. **สีเดิมทั้งหมด** — Tailwind gray, blue-500/600 (ปุ่มหลัก/ลิงก์), blue-50 (พื้นอ่อน), สีถ่านของโลโก้ (gray-700), สถานะ green/amber/red-600 บนพื้น -50 · ไม่เพิ่มสีใหม่
2. **หรูด้วยความเรียบ ไม่ใช่ลูกเล่น** — ระยะห่างมากขึ้น, ตัวอักษรน้ำหนักเบา (Kanit 300) หัวข้อน้ำหนักกลาง (500) แทนตัวหนา, ขอบบาง gray-200, เงาอ่อนมาก, มุมโค้ง 8–14px อย่างสม่ำเสมอ
3. **ไม่เปลี่ยนการทำงาน** — ไม่แตะ API, สิทธิ์, ข้อมูล · ปุ่ม/ลิงก์/ฟอร์มทำงานเหมือนเดิมทุกอย่าง เปลี่ยนแค่หน้าตาและการจัดวาง
4. **กติกาเดิมยังใช้** — ไม่มี tooltip (ยกเว้นชื่อเมนูตอนแถบข้างย่อ), ข้อความกำกับใต้ช่อง, error ค้างบนหน้า toast แจ้งสำเร็จเท่านั้น, ใช้ได้ที่จอมือถือ ~400px
5. **ทำผ่านส่วนประกอบกลาง** — แก้ที่ส่วนกลางครั้งเดียว ทุกหน้าที่ใช้ได้หน้าตาใหม่พร้อมกัน แล้วค่อยเก็บรายละเอียดรายหน้า

## โครงสร้างโค้ด
- `app/globals.css` — ตั้งตัวแปรธีม (`@theme`): ฟอนต์, เงา, มุมโค้ง · ลบ Arial ที่ค้าง · ไม่ประกาศสีใหม่ (ใช้สี Tailwind เดิม)
- `font/` — เพิ่มไฟล์ Kanit Light/Medium/SemiBold (ฟอนต์ OFL ฟรี ไม่ใช่ไลบรารี npm) ใน `app/layout.tsx`

## จุดเล็กที่ต้องระวัง (ตรวจแล้ว)
- **ฟอนต์**: ไฟล์ฟอนต์อยู่ในเครื่อง (`next/font/local`) ไม่โหลดจาก Google — หน้าพิมพ์เอกสาร (1A-4) ต้องได้ฟอนต์ไทยครบแม้ไม่มีเน็ต · ตั้ง `display: swap` กันหน้าว่างระหว่างโหลด
- **Tailwind v4**: สีเดิมเป็นชื่อมาตรฐาน (`blue-500`) ไม่สร้างชื่อสีใหม่ใน `@theme` — กันหลุดธีมในอนาคต
- **เมนูมือถือ**: แถบข้างเปิดเป็นลิ้นชักทับหน้า ปิดด้วย Esc/แตะนอกเมนู/เลือกเมนูแล้วปิดเอง (มีอยู่แล้ว ตรวจซ้ำ)
- **ตาราง → การ์ดบนมือถือ**: ตารางที่มีหลายคอลัมน์ต้องเลือกคอลัมน์หลักที่แสดงบนการ์ด — กำหนดต่อหน้าใน datatable (`mobileTitle`, `mobileMeta`)
- **แถบ "ยังไม่บันทึก"**: เตือนเมื่อจะออกจากหน้าโดยยังไม่บันทึกด้วย (beforeunload + ลิงก์ในระบบ) — ฟอร์มยาวอย่างตั้งค่าบริษัทเจ็บที่สุดถ้าลืม
- **ปุ่มไอคอนล้วน**: ห้าม (ต้องเดาความหมาย และห้าม tooltip) — ใช้ไอคอน+ตัวหนังสือ หรือเมนู "อื่นๆ" ที่มีชื่อการกระทำ
- **โฟกัสคีย์บอร์ด**: ทุกปุ่ม/ช่องมีวงโฟกัสเห็นชัด · หน้าต่างยืนยันจับโฟกัสไว้ข้างใน
- **ลดการเคลื่อนไหว**: เคารพ `prefers-reduced-motion`
- **โหมดมืด**: ยังไม่ทำ (ระบบไม่เคยมี) — โครงตัวแปรธีมเตรียมไว้ให้เพิ่มได้ภายหลัง
- **ภาพหน้าจอ**: ไม่มีเครื่องมือจับภาพอัตโนมัติ (ต้องขอติดตั้ง Playwright ถ้าต้องการ) — ตรวจด้วย tsc/eslint/build + เจ้าของระบบเปิดดูหลังแต่ละขั้น

## รายการงานขั้น U1 (ละเอียด — ทำตามลำดับ)
1. **ฟอนต์**: เพิ่ม `font/Kanit-Light.ttf`, `Kanit-Medium.ttf`, `Kanit-SemiBold.ttf` (Google Fonts, OFL — เก็บไฟล์สัญญาอนุญาต `font/OFL.txt` ไว้ด้วย) · `app/layout.tsx` ใช้ `localFont` หลายน้ำหนัก `display: "swap"` · `globals.css` ลบ Arial ที่ทับ Kanit · ตั้ง `--font-sans` ใน `@theme` ให้ Tailwind ใช้ Kanit ทุกที่
2. **ตัวแปรธีม** (`globals.css` `@theme`): เงา (`shadow-card`, `shadow-float`), มุมโค้ง, ไล่เฉด `bg-brand-gradient` (blue-500→600) — ไม่ประกาศสีใหม่ ใช้ชื่อสี Tailwind เดิม · พื้นหน้า gray-50 + แสงฟ้าจางด้านบน
3. **ส่วนประกอบกลาง** `components/ui/`: `button.tsx` (primary ไล่เฉด / secondary / ghost / danger × md/sm) · `card.tsx` · `page-header.tsx` (eyebrow + หัวข้อ + คำอธิบาย + ปุ่ม) · `status-pill.tsx` · `segmented.tsx` (มีตัวเลข) · `stat-card.tsx` · `empty-state.tsx` · `skeleton.tsx` · `row-menu.tsx` (เมนู "อื่นๆ" ปิดด้วย Esc/คลิกนอก) · `switch.tsx` · `unsaved-bar.tsx` (+ เตือนก่อนออกจากหน้า)
4. **เปลือก**: แถบข้างการ์ดลอย (กลุ่ม "เมนูหลัก/ผู้ดูแลระบบ" — แค่หัวกลุ่ม ไม่เปลี่ยน MENU_DEFS) · ปุ่มค้นหา (ใช้ `/dashboard/search` เดิม เปิดด้วย Ctrl K) · การ์ดผู้ใช้ด้านล่าง · แถบบนกระจก + เส้นทางหน้า · มือถือเป็นลิ้นชัก · ชื่อเมนูตอนแถบย่อยังเป็นข้อยกเว้น tooltip เดียว
5. **ของเดิมที่ทุกหน้าใช้**: `datatable` (หน้าตาใหม่ + การ์ดบนมือถือ) · `ConfirmDialog` → แบบใหม่ (ไอคอนกรอบสี, รายการผลที่จะเกิด, ปุ่มเต็มแถว, มือถือเลื่อนขึ้นจากล่าง) · `Input`, `SearchableSelect`, `Button/*` เดิมเปลี่ยนหน้าตาให้ตรงแบบใหม่ (API เดิม ไม่ต้องแก้หน้าที่เรียก)
6. **หน้าเข้าสู่ระบบ** แบบสองฝั่ง · **หน้าตั้งค่าบริษัท** ย้ายมาใช้ส่วนประกอบใหม่ (เป็นหน้าตัวอย่างจริงหน้าแรก)
