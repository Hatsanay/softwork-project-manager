# คำถามความต้องการ: สินค้าเลือกคำถาม (แทนกลุ่มเลือกหมวด/สินค้า)

สถานะ: **เขียนโค๊ดแล้ว 1 พ.ย. 2026 (ยังไม่ commit) · คำตอบข้อ 7 ทุกข้อ = ก (ตามที่แนะนำ) · ผลอยู่ข้อ 8**

ที่มา: ผู้ใช้ "ก่อนเขียนโค๊ดตามแผน ผมอยากแก้โครงสร้างคำถาม ผมอยากให้สินค้าเลือกคำถาม ไม่ใช่เลือกหมวดหมู่ และไม่ใช่หมวดหมู่เลือกคำถาม" (1 พ.ย. 2026)

## 1. ตอนนี้ (Q-1 ถึง Q-3 · 26 ต.ค. 2026)

- คำถาม (`tb_requirement_questions`) อยู่ในกลุ่ม (`tb_requirement_groups`) · ข้อลูกถามตามคำตอบข้อแม่ในกลุ่มเดียวกัน
- **กลุ่มเป็นคนเลือก**ว่าถามเมื่อไร (`rqg_trigger`): ถามทุกคำขอ · ถามตามที่เลือก (ผูก หมวด `tb_requirement_group_categories` / ชุด `..._packages` / สินค้า `..._products`) · ถามเฉพาะลิงก์ที่ถามเพิ่ม
- ลิงก์เพิ่ม/ตัดทั้งกลุ่ม (`tb_order_link_requirement_groups`)
- หน้าสินค้ามีแผง "คำถามของรายการนี้" แสดงอย่างเดียว ต้องไปแก้ที่แท็บคำถาม

ปัญหา: คิดจากมุมกลุ่ม ("กลุ่มนี้ถามหมวดไหน") แต่ทีมคิดจากมุมสินค้า ("ขายโดเมน ต้องถามชื่อโดเมน") · ผูกทั้งหมวด = สินค้าทุกตัวในหมวดได้คำถามเหมือนกันหมด

## 2. แนวคิดใหม่

- **กลุ่ม = หัวข้อสำหรับจัดหน้าและเรียงลำดับเท่านั้น** (ลูกค้าเห็นหัวข้อ "เว็บไซต์" "โดเมน") · ไม่ผูกหมวด/สินค้าอีก
- **สินค้า/ชุดรายการเลือกคำถามเอง** ทีละข้อ (หรือกดเลือกทั้งหัวข้อ)
- คงไว้: กลุ่ม "ถามทุกคำขอ" (เช่น ข้อมูลธุรกิจ ช่องทางติดต่อ) · กลุ่ม "ถามเฉพาะลิงก์ที่ถามเพิ่ม" · ลิงก์เพิ่ม/ตัดกลุ่ม · ข้อลูก · ชนิดลิงก์ที่ถาม · ไม่ถามเมื่อทีมเลือกรายการให้ · เติมคำตอบเดิม

## 3. ฐานข้อมูล

- ใหม่ `tb_product_questions` (`pq_product_id` FK products ON DELETE CASCADE · `pq_question_id` FK questions ON DELETE CASCADE · PK คู่)
- ใหม่ `tb_package_questions` (`kq_package_id` · `kq_question_id` · แบบเดียวกัน)
- `rqg_trigger`: `'selection'` เปลี่ยนความหมายเป็น "ถามเมื่อลูกค้าเลือกสินค้าที่ผูกคำถามในหัวข้อนี้" (ชื่อบนจอ "ถามตามสินค้าที่เลือก")
- **ย้ายข้อมูลเดิมให้เอง (deploy_schema.sql · รันครั้งเดียว: ตารางใหม่ว่าง และตารางเดิมมีข้อมูล)**:
  - กลุ่มผูกสินค้า → สินค้านั้นเลือกทุกข้อแม่ในกลุ่ม
  - กลุ่มผูกหมวด → **สินค้าทุกตัวในหมวดนั้น** (ที่เปิดใช้งาน) เลือกทุกข้อแม่ในกลุ่ม · ชุดรายการในหมวดนั้นด้วย
  - กลุ่มผูกชุด → ชุดนั้นเลือกทุกข้อแม่ในกลุ่ม
  - ผลเหมือนเดิมสำหรับลูกค้า (เห็นคำถามชุดเดิม) · ตารางผูกเดิมเก็บไว้ 1 รอบ deploy แล้วค่อยลบ (กันย้อนกลับไม่ได้) · หน้าเว็บ/backend เลิกอ่านทันที
- ข้อแม่/ข้อลูก: สินค้าเลือกได้เฉพาะ **ข้อแม่** (ข้อที่ไม่มีเงื่อนไข) · ข้อลูกตามข้อแม่ไปเอง (ถามตามคำตอบ) · ข้อมูลไม่เก็บข้อลูกในตารางผูก

## 4. ลูกค้าเห็นข้อไหน (`visibleQuestionnaire`)

- ข้อที่ถาม = กลุ่ม "ถามทุกคำขอ" ทั้งกลุ่ม ∪ **ข้อที่สินค้า/ชุดที่ลูกค้าเลือกผูกไว้** (ไม่ซ้ำ) ∪ กลุ่มที่ลิงก์สั่งถามเพิ่ม − กลุ่มที่ลิงก์ตัด
- **ชุดรายการ = คำถามที่ชุดเลือก ∪ คำถามของสินค้าในชุด** (Q2) · เลือกสินค้าซ้ำหลายตัว คำถามไม่ซ้ำ
- แสดงตามหัวข้อ (กลุ่ม) และลำดับข้อเดิม · หัวข้อที่ไม่มีข้อถูกเลือก = ไม่ขึ้น
- ข้อมูลที่ลูกค้าตอบแล้ว (`tb_service_request_answers`) เก็บชื่อกลุ่ม/ข้อความ ณ วันส่งอยู่แล้ว ไม่กระทบ

## 5. หน้าจอ

- **แผงสินค้า / แผงชุดรายการ:** ส่วนใหม่ **"คำถามที่ถามลูกค้า"** (แทนแผงแสดงอย่างเดียวเดิม):
  - รายการติ๊กตามหัวข้อ (ข้อแม่) · ติ๊กหัวข้อ = ทั้งหัวข้อ · ข้อที่มีข้อลูกบอก "+ ถามต่อ N ข้อตามคำตอบ"
  - บรรทัดบนบอก "ลูกค้าตอบเพิ่ม N ข้อ ราว M นาที เมื่อเลือกรายการนี้" (ใช้ `questionnaireSummary` เดิม)
  - หัวข้อ "ถามทุกคำขอ" แสดงเป็นข้อมูล (ติ๊กไม่ได้ ถามอยู่แล้ว)
  - ชุดรายการบอกเพิ่ม "รวมคำถามของสินค้าในชุดให้อัตโนมัติ N ข้อ" (ดูได้ ติ๊กออกไม่ได้)
  - ปุ่ม "สร้างคำถามใหม่" พาไปแท็บคำถาม (กลับมาแล้วติ๊กได้)
- **แท็บคำถาม:** แก้กลุ่มไม่มีส่วนผูกหมวด/ชุด/สินค้าแล้ว · ตัวเลือกถามเมื่อไร: ถามทุกคำขอ / **ถามตามสินค้าที่เลือก** / ถามเฉพาะลิงก์ที่ถามเพิ่ม · แต่ละข้อแสดง "ถามเมื่อเลือก: จดโดเมน, เว็บธุรกิจ" (อ่านอย่างเดียว · กดชื่อเปิดแผงสินค้า)
- **ดูมุมมองลูกค้า** (มีอยู่แล้ว): เลือกสินค้า/ชุดเพื่อดูว่าลูกค้าเห็นข้อไหน ใช้กติกาใหม่
- คำอธิบายบนจอ ไม่มี tooltip · ไม่มี em dash

## 6. จุดที่ต้องระวัง

- **ข้อที่ถูกปิดใช้งาน/ลบ:** ลบ = หลุดจากสินค้าเอง (CASCADE) · ปิดใช้งาน = ไม่ถาม แต่สินค้ายังจำไว้ (เปิดกลับมาก็ถามต่อ)
- **ย้ายข้อไปกลุ่มอื่น** (มีอยู่แล้ว): การผูกสินค้าติดไปกับข้อ
- **ข้อแม่กลายเป็นข้อลูก** (แก้เงื่อนไขทีหลัง): การผูกของข้อนั้นถูกลบ (ข้อลูกตามข้อแม่) · บอกบนจอก่อนบันทึก "ข้อนี้ผูกกับสินค้า N รายการ จะถูกเอาออก"
- **สินค้าแบบ % / ปิดใช้งาน:** เลือกคำถามได้ตามปกติ
- **ลิงก์ที่ทีมเลือกรายการให้ + "ไม่ถามเมื่อทีมเลือกรายการให้":** กติกาเดิม
- **ข้อมูลจำลอง 2 ชุด:** ใช้การผูกแบบใหม่ (สคริปต์ `linkRequirementGroups` เปลี่ยนเป็นผูกที่สินค้า) · สร้างไฟล์ใหม่ + `mock:verify`
- **deploy_schema.sql:** ตาราง 2 ตัว + ย้ายข้อมูล (idempotent: INSERT IGNORE + เงื่อนไขรันครั้งเดียว) + manifest · reset_all_data.sql ล้างตารางใหม่ · เทสต์อัปเกรดจากโครงสร้างเดิมที่มีการผูกหมวด

## 7. คำถาม (ตอบ "ตามที่แนะนำ" ได้)

- **Q1 สินค้าเลือกระดับไหน:** ก) ทีละข้อ (มีปุ่มเลือกทั้งหัวข้อ) (แนะนำ · ละเอียดพอสำหรับโดเมน) · ข) ทั้งกลุ่ม
- **Q2 ชุดรายการ:** ก) คำถามที่ชุดเลือก + คำถามของสินค้าในชุดให้เอง (แนะนำ · ตั้งครั้งเดียวที่สินค้า) · ข) ชุดเลือกเองทั้งหมด
- **Q3 กลุ่ม "ถามทุกคำขอ":** ก) คงไว้ (แนะนำ · ข้อมูลธุรกิจ/ติดต่อถามทุกครั้ง) · ข) เลิก ให้ทุกอย่างผ่านสินค้า
- **Q4 ข้อมูลเดิม:** ก) ย้ายให้อัตโนมัติ ลูกค้าเห็นเหมือนเดิม (แนะนำ) · ข) เริ่มผูกใหม่เอง
- **Q5 ลิงก์เพิ่ม/ตัดคำถาม:** ก) ทั้งกลุ่มแบบเดิม (แนะนำ · ไม่แก้หน้าลิงก์) · ข) ทีละข้อ

## 8. ผลการทำ (1 พ.ย. 2026)

- **ฐานข้อมูล:** `tb_product_questions` · `tb_package_questions` (+ manifest · reset_all_data.sql) · ย้ายข้อมูลอยู่ท้ายส่วนที่ 4 ของ deploy_schema.sql
  - **ต่างจากแบบข้อ 3:** ย้ายแล้ว **ล้างแถวในตารางผูกเดิม** (โครงตารางยังอยู่) แทนการเช็ก "รันครั้งเดียว" · deploy รอบถัดไปไม่มีอะไรให้ย้าย ทีมเอาคำถามออกจากสินค้าแล้วไม่ถูกผูกกลับ · ย้อนกลับต้องใช้ backup
  - ผูกหมวด → สินค้า**ทุกตัว**ในหมวด (รวมที่ปิดใช้งาน เปิดกลับมาก็ถามเหมือนเดิม) + ชุดในหมวด · ผูกเฉพาะข้อแม่
  - ตารางผูกเดิม 3 ตัว (`tb_requirement_group_categories/_packages/_products`) ลบได้ใน deploy รอบถัดไป
- **API:** `PUT /V1/products/:id/questions` · `PUT /V1/product-packages/:id/questions` (สิทธิ์ productManagement · แทนชุดเดิมทั้งหมด · ข้อลูก/ข้อที่ไม่มีจริง = 400) · กลุ่มไม่รับ `category_ids/package_ids/product_ids` แล้ว · `GET /V1/requirement-groups` ส่ง `product_ids · package_ids · via_package_ids` ต่อข้อ · ข้อแม่ที่ถูกตั้งเป็นข้อลูก = เอาการผูกออก
- **กติกาที่ลูกค้าเห็น:** `visibleQuestionnaire` (shared) · `matched` เหลือ `package_ids/product_ids` · ผู้เรียกทุกที่เลิกส่ง categoryIds
- **หน้าจอ:** แผง "คำถามที่ถามลูกค้า" ในหน้าแก้สินค้า/ชุด (ติ๊กแล้วบันทึกทันที · ติ๊กทั้งกลุ่ม · ข้อของสินค้าในชุดติ๊กค้างไว้ให้ดู) · แผ่นแก้กลุ่มไม่มีส่วนผูกแล้ว · การ์ดคำถามบอก "ถามเมื่อเลือก: ..." (แสดง 4 ชื่อ + "และอีก N รายการ") · คำเตือนข้อที่ยังไม่มีสินค้าเลือก/มีแต่รายการที่ไม่แสดงบนหน้าร้าน · แผ่นแก้คำถามเตือนก่อนบันทึกเมื่อข้อแม่จะกลายเป็นข้อลูก
  - กดชื่อสินค้า/ชุดใน "ถามเมื่อเลือก" = ไปแท็บสินค้า/ชุดและเปิดแผงแก้รายการนั้น (ทำเพิ่ม 1 พ.ย. 2026)
  - กลุ่ม "ไม่ถามเอง" ไม่อยู่ในรายการติ๊ก (แผงบอกให้เปลี่ยนเป็นถามตามสินค้าที่เลือกก่อน)
- **เทสต์:** ทุกเทสต์คำถาม/หน้าร้านใช้การผูกแบบใหม่ · เพิ่มเทสต์ย้ายข้อมูล (deploy-schema) · ข้อมูลจำลองใช้ `askGroupQuestions` แทน `linkRequirementGroups`
