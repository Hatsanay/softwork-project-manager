# แผนงาน (Plans)

โฟลเดอร์นี้เก็บแผนงานของโปรเจกต์ไว้ใน git เพื่อไม่ให้หายไปพร้อมประวัติแชทของ Claude Code

- แผนจาก Plan mode ของ Claude Code จะถูกบันทึกมาที่นี่อัตโนมัติ (ตั้งค่า `plansDirectory` ใน `.claude/settings.json`)
- แผนที่เขียนเอง ตั้งชื่อไฟล์แบบ `YYYY-MM-DD-หัวข้อ.md` เช่น `2026-10-07-dashboard-kpi.md`
- ทำเสร็จแล้วให้ commit ไว้ทุกครั้ง
