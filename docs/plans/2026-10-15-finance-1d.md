## 1. ขอบเขต

**ทำใน 1D**
1. **การเงินโปรเจกต์** — ส่วนใหม่ในหน้าโปรเจกต์: มูลค่าตามสัญญา / ออกบิลแล้ว / รับแล้ว / ค้างรับ / ยังไม่ออกบิล · งวดถัดไปที่ยังไม่ออกบิล · เทียบ "งานเสร็จกี่ % ของมูลค่า" กับ "ออกบิลไปกี่ %"
2. **รายงานขาย** — เปิดเมนู "รายงาน" (ตอนนี้เป็นหน้าว่าง): สรุปตามช่วงเวลา + กราฟ 12 เดือน (ออกบิล vs รับเงิน) + ลูกค้ายอดสูงสุด + อัตราปิดการขายของใบเสนอราคา
3. **ไฟล์ส่งนักบัญชีรายเดือน** — ปุ่มส่งออกในหน้ารายงาน (รายละเอียดชีตข้อ 3.3)

**ไม่ทำใน 1D**
- ปิดงวดบัญชี / ล็อกไม่ให้แก้เดือนที่ส่งไปแล้ว → เฟส 3 (ข้อ 6 R-D2 อธิบายผลกระทบระหว่างนี้)
- รายงานภาษีขาย (ภ.พ.30) / ใบกำกับภาษี → ก่อนจด VAT (B1/B4)
- งบการเงิน / GL → เฟส 3
- ส่งอีเมลรายงานอัตโนมัติ → ภายหลัง

## 3. กติกาการคำนวณ

### 3.1 การเงินโปรเจกต์ (แยกตามสกุลเงิน + รวมเป็นบาท)
| ตัวเลข | นับจาก |
|---|---|
| มูลค่าตามสัญญา | ใบเสนอราคาสถานะ **ลูกค้าตอบรับ** ที่ผูกโปรเจกต์นี้ (`qt_total`) — ใบที่ถูกแทนด้วย revision ไม่นับ (สถานะ superseded) |
| ออกบิลแล้ว | ใบแจ้งหนี้ **ออกแล้ว** (ไม่นับร่าง/รออนุมัติ/ยกเลิก) ที่ผูกโปรเจกต์ (`inv_total`) — แยก "ตามใบเสนอราคา" กับ "สร้างเอง (นอกสัญญา)" |
| รับแล้ว / ค้างรับ / เกินกำหนด | `inv_paid_amount` ของใบที่ออกแล้ว · ค้าง = ออกบิล − รับแล้ว · เกินกำหนด = ค้างของใบที่เลยวันครบกำหนด (เวลาไทย) |
| ยังไม่ออกบิล | ยอดงวดของใบเสนอราคาที่ตอบรับแล้วที่ยังไม่อยู่ในใบแจ้งหนี้ที่ออกแล้ว (ร่างนับเป็น "ร่างรอออก") · งวดถัดไป = งวดลำดับแรกที่ยังว่าง |
| เป็นบาท | ใบเสนอราคา `qt_total_thb` · ใบแจ้งหนี้ `inv_total_thb` (อัตราวันออก) · รับแล้วใช้ยอดบาทตามอัตราใบแจ้งหนี้ (`rca_amount_thb`) เพื่อให้ ค้าง = ออกบิล − รับ ลงตัว · ส่วนต่างอัตราแสดงแยก |

**งานเสร็จเทียบการออกบิล** (ต่อใบเสนอราคาที่ตอบรับ): รายการที่มีงานผูก (`task_quotation_item_id`) → สัดส่วนงานที่เสร็จ (`done`) ของรายการนั้น × ยอดรายการ รวมกันหารยอดรวมของรายการที่มีงานผูก = "งานเสร็จประมาณ X% ของมูลค่า" · เทียบกับ "ออกบิลไป Y%" · X > Y เกิน 10 จุด → ข้อความ "งานเดินหน้ากว่าการเก็บเงิน — ตรวจว่าถึงงวดถัดไปหรือยัง" (ข้อมูลช่วยตัดสินใจ ไม่บังคับอะไร) · รายการที่ไม่มีงานผูกไม่นับและบอกจำนวนไว้

### 3.2 รายงานขาย (ช่วงเวลา: เดือน / ไตรมาส / ปี / กำหนดเอง · วันที่เอกสาร เวลาไทย)
- **ออกบิล** = ผลรวมยอดก่อน VAT เป็นบาท (`inv_after_discount_thb`) ของใบที่ออกในช่วงและยังไม่ยกเลิก — ใบที่ยกเลิกทีหลังหายจากช่วงเดิม (ข้อ 6 R-D2)
- **รับเงิน** = เงินเข้าจริงเป็นบาท (`rc_received_thb`) + หัก ณ ที่จ่าย + ค่าธรรมเนียม (เป็นบาท) ของใบเสร็จวันที่ในช่วงที่ไม่ยกเลิก — แยกแสดงสามส่วน
- **ใบเสนอราคา**: ตอบรับในช่วง (จำนวน/มูลค่า) · อัตราปิดการขาย = ตอบรับ ÷ (ตอบรับ + ปฏิเสธ + หมดอายุ) ของใบที่จบผลในช่วง
- **กราฟ 12 เดือน**: แท่งออกบิล vs รับเงิน ต่อเดือน (วาดด้วย CSS ไม่เพิ่มไลบรารีกราฟ — มือถือเลื่อนซ้ายขวาในกรอบ)
- **ลูกค้ายอดสูงสุด 10 ราย** ตามยอดออกบิลในช่วง + ค้างรับปัจจุบัน

### 3.3 ไฟล์ส่งนักบัญชี (ต่อเดือน — ร่างให้นักบัญชีตรวจ B4)
| ชีต | เนื้อหา |
|---|---|
| สรุป | ชื่อบริษัท/เลขผู้เสียภาษี เดือน วันเวลาที่ส่งออก ผู้ส่งออก · ยอดรวมของทุกชีต · คำเตือน R-D2 |
| ใบแจ้งหนี้ | ทุกใบที่ **ออก** ในเดือน (รวมที่ยกเลิกแล้ว — มีคอลัมน์สถานะ + วันยกเลิก + เหตุผล): เลขที่ วันที่ ครบกำหนด ลูกค้า เลขผู้เสียภาษี สาขาลูกค้า (จาก snapshot) สกุล อัตรา ยอดก่อน VAT / VAT / รวม (สกุลเดิม + บาท) หัก ณ ที่จ่ายโดยประมาณ อ้างอิงใบเสนอราคา/โปรเจกต์ |
| ใบเสร็จ | ทุกใบที่ **วันที่รับเงิน** อยู่ในเดือน (รวมที่ยกเลิก): เลขที่ วันที่ ลูกค้า ใบแจ้งหนี้ที่ตัด (หนึ่งแถวต่อใบที่ตัด) วิธีรับ บัญชี/เช็ค ยอดตัด หัก ณ ที่จ่าย ค่าธรรมเนียม เงินเข้า (สกุลเดิม + บาท) อัตราจริง ส่วนต่างอัตรา |
| หัก ณ ที่จ่าย | ใบเสร็จที่มีหักในเดือน: ลูกค้า เลขผู้เสียภาษี เลขที่/วันที่ 50 ทวิ ยอดหัก มีไฟล์หรือยัง — ใช้ตามเก็บ 50 ทวิ ก่อนยื่นภาษีสิ้นปี |
| ลูกหนี้ ณ สิ้นเดือน | ยอดค้างของทุกใบ **ณ วันสุดท้ายของเดือน** แยกช่วงอายุ (คิดย้อนหลังจากใบเสร็จ — ข้อ 6 R-D3) |
| ยกเลิกในเดือน | ใบแจ้งหนี้/ใบวางบิล/ใบเสร็จที่ **ถูกยกเลิก** ในเดือน (แม้ออกเดือนก่อน) — นักบัญชีต้องกลับรายการ |

ตัวเลขทุกช่องเป็นตัวเลขจริง (ไม่ใช่ข้อความ) · วันที่เป็นวันที่จริง · เลขผู้เสียภาษี/เลขที่เอกสารเป็นข้อความ (ศูนย์นำหน้าไม่หาย) · หัวตารางตรึงแถวแรก · ชื่อไฟล์ `softwork-บัญชี-2026-10.xlsx`

## 4. หน้าจอ (ทุกหน้าผ่านกติกามือถือ CODING_GUIDELINES 5.1)

| หน้า | เนื้อหา |
|---|---|
| โปรเจกต์ (view) — ส่วน "การเงิน" (ตาม D1) | การ์ดตัวเลข 5 ช่อง (สัญญา/ออกบิล/รับแล้ว/ค้าง/ยังไม่ออกบิล) · แถบเทียบงานเสร็จ vs ออกบิล · รายการใบเสนอราคาที่ตอบรับ + งวด (ออกบิลแล้ว `IV-…` / ร่าง / ยังไม่ออก — ลิงก์) · ใบแจ้งหนี้สร้างเองของโปรเจกต์ · ปุ่ม "ออกใบแจ้งหนี้งวดถัดไป" |
| `/reports` (เดิมว่าง) → "รายงานขาย" | ตัวเลือกช่วงเวลา · การ์ดสรุป · กราฟ 12 เดือน · ลูกค้ายอดสูงสุด · อัตราปิดการขาย · กล่อง "ไฟล์ส่งนักบัญชี" (เลือกเดือน → ดาวน์โหลด) · ลิงก์ไปลูกหนี้คงค้าง |
| เมนู | เปิดเมนู "รายงาน" (ตาม D3) |

**ข้อความกำกับ (ร่าง)**
- ออกบิล: "ยอดก่อน VAT ของใบแจ้งหนี้ที่ออกในช่วงนี้ (ไม่นับใบที่ยกเลิก) · สกุลต่างประเทศคิดเป็นบาทตามอัตราวันออกใบ"
- รับเงิน: "เงินที่เข้าบัญชีจริงตามวันที่ในใบเสร็จ + หัก ณ ที่จ่าย + ค่าธรรมเนียม"
- ไฟล์นักบัญชี: "ใบเสร็จย้อนวันที่ได้ 30 วัน — ตัวเลขของเดือนก่อนอาจเปลี่ยนได้จนถึงวันที่ 30 ของเดือนถัดไป ส่งออกใหม่ถ้าแก้ย้อนหลัง"
- งานเสร็จ vs ออกบิล: "ประมาณจากสัดส่วนงานที่เสร็จของแต่ละรายการ คูณมูลค่ารายการ — ใช้ช่วยตัดสินใจว่าถึงงวดถัดไปหรือยัง"

## 7. เทสต์ที่ต้องผ่าน
- การเงินโปรเจกต์: สัญญา/ออกบิล/รับ/ค้าง/ยังไม่ออก กับใบเสนอราคา 2 ใบ (บาท + USD) + ใบสร้างเอง + ใบยกเลิก + revision · % งานเสร็จ · สิทธิ์ (สมาชิกไม่มีสิทธิ์ = 403)
- รายงานขาย: ขอบช่วงวันที่ · ใบยกเลิกไม่นับ · ยอดบาทของใบ USD · อัตราปิดการขาย · 12 เดือนมีเดือนที่เป็นศูนย์
- ไฟล์นักบัญชี: เปิดไฟล์ที่ได้แล้วตรวจชื่อชีต/แถว/ชนิดเซลล์ (ตัวเลข/วันที่/ข้อความ) · ลูกหนี้ ณ สิ้นเดือน (ใบเสร็จต้นเดือนถัดไป, ยกเลิกทีหลัง) · injection · audit log · สองเขตเวลา
- ภาพหน้าจอ: จอคอม + มือถือ 360/400px
